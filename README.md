Forecasts GTA VI's launch-day Twitch viewers for hours 2–24 from the first hour's print: per-hour log-ratios from comparable past launches, filtered to rolling-unlock shapes, weighted by similarity of scale, with quantiles blended from the empirical pool and a normal fit. In leave-one-out validation over 37 real launches it beats the house baseline's pinball loss by roughly a quarter on rolling launches.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
